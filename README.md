# Hades Portfolio

A lightweight personal portfolio website for **Hades**, an anonymous Web3 contributor focused on community moderation, security research, user support, documentation, and practical learning.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript

## Files

- `index.html` — page structure and content
- `style.css` — responsive dark theme, layout, cards, animations, and visual styling
- `script.js` — mobile navigation, scroll progress, fade-in animation, and copy-email behavior
- `README.md` — project overview and deployment notes

## Features

- Mobile-first responsive design
- Dark, professional interface with a subtle security atmosphere
- Smooth scrolling
- Responsive navigation menu
- Scroll progress indicator
- Fade-in section animations
- Copy email button
- Clean hover states
- Lightweight static build with no framework dependency

## Run Locally

Open `index.html` directly in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Add these files to the repository root:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Commit and push the files to GitHub.
4. In the GitHub repository, open **Settings**.
5. Go to **Pages**.
6. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
7. Select the main branch and the root folder.
8. Save the settings.
9. GitHub Pages will publish the site and show the live URL once deployment finishes.

## Customization

Contact links are maintained in `index.html` for Telegram, Discord, X/Twitter, and email.
